## Release

How this repository is released is described in `RELEASING.md` (humans) and summarised here (agents). The process is shared by all watergate-ai services and implemented in `watergate-ai/release-workflows`; this repository only contains the caller files generated by `release-init`.

This repository is **non-deployable**: there is no release pipeline. Do not add release, deploy or tag automation to it; if that changes, run `release-init` and follow `RELEASING.md`. `.github/workflows/appsec.yml` (first line `# release-init: managed`) is owned by `release-init`: do not edit it without a pull request that a platform owner reviews; refresh it by re-running `release-init`.
